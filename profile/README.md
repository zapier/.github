# Zapier ⚡

Give any AI governed access to 9,000+ apps. No code, no infrastructure, SOC 2 Type II certified.

## Quick Start

### Connect your AI  🔌

Setup guides for every supported client:

- [Claude](https://docs.zapier.com/mcp/get-started/connect/claude.md)
- [ChatGPT](https://docs.zapier.com/mcp/get-started/connect/chatgpt.md)
- [Claude Code](https://docs.zapier.com/mcp/get-started/connect/claude-code.md)
- [Cursor](https://docs.zapier.com/mcp/get-started/connect/cursor.md)

Not seeing your client? See the [full list of supported clients](https://docs.zapier.com/mcp/clients).
  
### Build in code  💻

Scaffold a project, install the SDK, and log in with one command:

```bash
npx @zapier/zapier-sdk-cli init my-project
```

## Primitives

- [Zapier MCP](https://docs.zapier.com/mcp/home) — Connect AI apps like Claude, ChatGPT, and Cursor to 9,000+ apps through a single MCP server.
- [Zapier SDK](https://docs.zapier.com/sdk/home) — Authenticated, governed access to the full Zapier catalog in code, on behalf of your users. Includes a CLI for managing connections and testing from the terminal.
